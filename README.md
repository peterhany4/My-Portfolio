# Personal Developer Portfolio — Peter Hany

A modern, responsive, accessible, and fast personal portfolio built as a frontend React application, representing Peter Hany as a **Computer Science Student & Software Developer** who is continuously building, learning, and exploring new areas of software development.

## Features

- **Single-Page Architecture**: Clean visual hierarchy and smooth anchor navigation across all portfolio sections.
- **Light & Dark Themes**: Full theme support respecting system preferences with persistent manual toggling.
- **Evidence-Based Projects**: Showcases featured and additional projects linked directly to verified GitHub repositories.
- **Spec-Driven Development**: Engineered incrementally through structured specifications, plans, and verification gates.
- **Accessibility & Performance**: Optimized for keyboard navigation, screen readers, reduced-motion preferences, and rapid production bundling.

---

## Tech Stack

- **Framework**: React 18+ with TypeScript
- **Styling**: Tailwind CSS
- **Build Tool**: Vite
- **Icons**: Lucide React

---

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm

### Installation & Development

1. Clone the repository:
   ```bash
   git clone https://github.com/peterhany4/My-Portfolio.git
   cd My-Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
