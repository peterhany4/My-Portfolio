# Quickstart Guide: Portfolio Foundation (Feature 001)

## Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

## Setup & Installation

1. **Clone and Navigate**:
   ```bash
   git clone https://github.com/peterhany4/My-Portfolio.git
   cd My-Portfolio
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Verify Production Build**:
   ```bash
   npm run build
   npm run preview
   ```

5. **Directory Structure Verification**:
   Ensure `src/` contains:
   - `components/` (reusable UI)
   - `sections/` (page sections)
   - `data/` (separated content schemas)
   - `assets/` (images, icons)
   - `utils/` (helpers)
