# Quickstart Guide: Hero Section (Feature 004)

## Validation Scenarios

1. **Verify Hero Content & Identity**:
   - Start dev server: `npm run dev`
   - Verify developer identity and headline are immediately visible above the fold.

2. **Verify CTA Navigation**:
   - Click "View Projects" primary button.
   - Verify smooth scrolling to the featured projects section.

3. **Verify Accessibility**:
   - Tab through all hero buttons and links.
   - Confirm visible focus rings and correct keyboard navigation.
